# Core Rules

## Canon status

- Repository 3100 is dedicated to this one fantasy setting.
- `WORLD_SETTING.md` contains the currently established world framework.
- The protagonist is not yet defined.
- Do not import characters, summoning rules, statistics, relationships, or other facts from unrelated fantasy projects.

## Worldbuilding policy

- Start from a familiar sword-and-magic fantasy baseline.
- Add detail when it becomes relevant instead of prebuilding everything.
- Once the user confirms a setting element, preserve it unless the user later changes it.
- Do not silently rewrite established facts for scene convenience.
- Distinguish brainstorming from confirmed canon. Only confirmed or actually adopted material should be written into the setting files.

## Repository update policy

When new canon is established, update the appropriate 3100 file promptly rather than waiting for a manual save command.

As the setting grows, split large subjects into dedicated files when useful, for example nations, magic, organizations, locations, characters, or history.
